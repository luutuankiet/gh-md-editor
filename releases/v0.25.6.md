# v0.25.6 — a diff stays open when it hands you a file

- **A diff is no longer eaten by the preview slot.** Opening a file from a diff — the working copy, or the file at either of the diff's refs — recycled the first unpinned, unmodified tab, and when the click came from a diff header that tab was usually the diff itself. The comparison you were reading vanished to show one of its own sides, which is the opposite of what the click asked for: those buttons exist so the file can be read *beside* the diff. v0.25.4 exempted the diff in one narrow case; the rule is now general and lives in one place — no opener recycles a diff except another diff, so stepping down a list of changed files still reuses a single tab the way it always has.

No storage format change and no server change.
