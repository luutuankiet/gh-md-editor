# v0.10.0 — reach the editor from anywhere, and keep your session

- **`--tunnel` puts the server on the public internet with one flag** — spawns a cloudflared quick tunnel and prints an HTTPS URL. No account, no signup, no port forwarding, no router config, and it opens on a phone. `--tunnel funnel` uses Tailscale Funnel instead for a stable hostname; `--tunnel-bin` points at a specific binary.
- **A tunnel always forces auth on, with a server-minted token** — 128 random bits, baked into the printed URL. This is the one place the permissive-by-default posture is deliberately overridden: a public URL plus the terminal endpoint would otherwise hand a shell to anyone who guessed the hostname.
- **A missing or dying tunnel binary never takes the server down** — it warns and keeps serving locally instead of exiting, and the tunnel process is signalled on shutdown so nothing strays.
- **Sessions survive closing the browser** — open tabs, split groups, diff views and panel state come back on reload, tracked per workspace folder. Restored files are re-read from disk so the mtime conflict guard stays honest, and a dirty buffer carries its draft along, so a crash no longer eats unsaved edits.
- **`Alt/Opt+N` opens a blank buffer; saving it asks where to put it** — a Save As dialog with a path input beside a live folder listing: click a folder to descend, `..` to go up, and typing filters the listing. Parent folders that do not exist yet are created on save.
- **`Cmd/Ctrl+click` multi-selects in the file explorer** — right-clicking a selection copies every file in it as one context payload, with overlapping picks de-duplicated.
- **Copied context carries absolute paths** — `<file src="…">` now resolves to the real filesystem path, so a payload pasted somewhere else is unambiguous. Two new context-menu items alongside it: copy full path, and open a new terminal in that folder.
