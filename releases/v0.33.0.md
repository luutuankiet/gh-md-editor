# v0.33.0: problems everywhere, plus Bash, Go and Rust

Problems from language servers now show up across the IDE, not only as underlines, and shell, Go and Rust files get language server support without anything heavy being installed for you.

## Problems everywhere

- **Explorer:** a file name takes the colour of its worst problem, with a count (`9+` above nine), and its parent folders get a dot. Gitignored files stay grey.
- **Scrollbar:** red, yellow and blue ticks down the right edge of each editor. Click one to jump there.
- **Status bar:** error and warning counts. Click them to open the new Problems panel.
- **Problems panel:** next to Terminal, grouped by file with errors first, with a filter box. Arrow keys, Enter or a click jump to the problem.

## Bash

- **Highlighting for `.zsh` files and shell startup files** such as `.bashrc`, `.zshrc`, `.profile` and `.envrc`.
- **bash-language-server,** started from the Language Servers panel. Hover a builtin for its help; with `shellcheck` on PATH, problems such as unquoted variables are flagged with a fix.
- **The status bar says when `shellcheck` or `shfmt` is missing,** and the server menu says what that costs and how to install it.

## Go and Rust

- **`gopls` and `rust-analyzer` are used only when they are on your PATH.** They are never downloaded or bundled.
- **`gopls` is offered when the file sits under a `go.mod`.** `rust-analyzer` starts only when you choose it, since it can use several GB of memory.
- **A missing binary gets its install command** in the status bar menu and the Language Servers panel, instead of a silent failure.
