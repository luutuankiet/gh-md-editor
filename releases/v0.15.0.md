# v0.15.0 — Tab indents, Cmd+G/Cmd+L reach the panels, and any two inputs can be diffed

- **Tab and Shift+Tab indent and outdent in code tabs** — nothing consumed the key, so the browser fell through to its own focus traversal and moved the cursor to the language picker instead of touching the document.
- **A macOS-safe chord for expand/shrink selection** — `Cmd+Ctrl+Shift+←/→`, because macOS claims plain `Ctrl+Shift+Arrow` at the window-server level and the page never sees it. Left expands on every platform, deliberately the inverse of the VS Code mac default, so the direction does not change per machine.
- **`Cmd+G` toggles source control, `Cmd+L` toggles the explorer** — alongside the existing `Cmd+Shift+G` and `Cmd+B`. `Cmd+B` stays because Chrome will not let a page cancel `Cmd+L`.
- **Find-next no longer fires with the panel toggle** — CodeMirror binds `Mod+G` and cancels the default without stopping propagation, so a window-level handler saw the same keystroke. The binding is dropped from both editors; `Enter` / `Shift+Enter` in the find field still step matches.
- **Compare the active file with another file, or with the clipboard** — two commands in the palette, rendered by the existing diff view. Staging controls are hidden because a compare has no index to write back to.
- **Pasting works where the clipboard API does not** — `navigator.clipboard` needs a secure context, and this server is routinely reached over plain http on a LAN, so a paste box takes over when the read is unavailable.
- **A file-to-file compare survives a reload; a pasted one does not** — pasted text exists only in memory, and persisting it would grow the saved session without bound.
