# v0.23.1 — opening a folder without losing the one you are in

A small release with one thing in it: the explorer's right-click menu can now
open a folder as a workspace somewhere other than the tab you are standing in.

## Open workspace in a new tab, or a new window

Right-clicking a folder in the explorer offered exactly one way to open it as a
workspace — `Open workspace here` — and "here" meant the current tab. Reaching
for it to glance at a sibling checkout replaced everything on screen: the open
editors, the splits, the terminal panel, all of it swapped out for the other
folder's session. The only way back was to open the old folder again and wait
for its session to restore.

The menu now offers all three destinations:

- `Open workspace here` — the current tab, unchanged
- `Open workspace in new tab` — a second browser tab, this one untouched
- `Open workspace in new window` — a separate browser window, sized for an IDE

This is the same set the recent-workspaces list has offered since v0.21.0, and
it is now literally the same code path behind it, so the two menus can no
longer drift apart. Both new entries appear only on folders, and only when a
single row is selected — a multi-selection has no one folder to open.
