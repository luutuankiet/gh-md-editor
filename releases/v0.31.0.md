# v0.31.0: language servers, readable diffs, and word wrap off by default

Code tabs in server mode could only guess at definitions and references by name, diff views painted a box behind every changed token until a new file was hard to read, and every editor wrapped long lines by default. This release adds opt-in language servers for TypeScript and Python, calms the diff colors, and turns word wrap off unless you ask for it.

## Language servers (opt-in)

- **Nothing starts on its own.** Open the palette and run `Start Language Server…`, pick `tsgo` (TypeScript 7), `ty` or `basedpyright`, then pick the folder it should serve. A server that is not installed is offered as a one-off download through `npx` or `uvx`, and you confirm the exact command first.
- **A new `Language Servers` tab in the bottom panel** lists each running server with its folder, language, how it was found, memory use and state, and has a Stop button for each.
- **Hover** shows types and docs from the server.
- **Cmd/Ctrl+Click** goes to the definition the server reports, and falls back to the old name lookup when no server covers the file.
- **Alt/Opt+X peeks the definition inline,** a few lines with the target highlighted and a `path:line` link. Escape or any edit closes it. It only takes the key when the cursor is on a name, so Opt+X still types on macOS elsewhere.
- **A right-click menu with Go to Definition, Peek Definition and Find All References** appears in files a server covers. Other files keep the browser's own menu.
- **Find All References** fills the existing references panel from the server.
- **Errors show inline at the end of the line,** with a tinted line, colored by severity. Only the most severe message per line is shown, and inline blame hides on those lines.
- **Completion** comes from the server while you type.
- **Gitignored folders stay out of results.** Definitions, references, symbols and diagnostics that point into gitignored paths such as `tmp/` are filtered out, so copies of other repos parked there do not pollute answers.
- **Two browser windows no longer fight over a server.** The window you are using owns it; the other detaches until you focus it again.

## Readable diffs

- **New files show a plain line tint,** with no box behind each token.
- **Changed words in modified lines keep a lighter highlight,** and syntax colors stay readable under it.
- **Merge conflicts are shown as line bands,** and the active conflict gets a stronger band with a rule on the left instead of an outline.

## Word wrap off by default

- **Editors no longer wrap long lines unless you turn wrap on.** Run `Toggle Word Wrap Default` from the palette to flip the default for all editors.
