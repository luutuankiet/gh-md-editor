# v0.36.0: search results that read like VS Code

Search results now show folder icons and path breadcrumbs, and the collapse button folds in steps.

## Search

- **Folder rows carry folder icons**, themed the same way as the explorer (a `tmp` folder gets the temp-folder icon), and the icon switches between open and closed as the row folds.
- **Squashed folder chains read as breadcrumbs:** a row standing for `src/lib/deep` shows `src / lib / deep` with dimmed separators.
- **The collapse button cycles in three steps.** From everything open, the first click folds every file so only file names show, the second folds the top-level folders, and the third opens everything again. The button's tooltip names the next step, and folding rows by hand in between never puts it out of step.
