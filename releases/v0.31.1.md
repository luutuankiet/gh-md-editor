# v0.31.1: a VS Code style peek, a readable hover card, and solid sticky rows

The language server views in v0.31.0 worked but were hard to read. Peek Definition showed plain uncoloured text, Find All References opened a separate panel at the bottom of the editor, the hover popup could stretch into one very long line, and the sticky scroll rows let the code underneath show through.

## One inline peek for definitions and references

- **Peek Definition, Find All References and the "N references" lens now open the same inline peek** under the line, in place of the old plain-text box and the separate references panel.
- **The code on the left is syntax highlighted** with the same colours as the main editor, scrolled to the target with the line tinted and the name boxed.
- **The list on the right is grouped by file.** Click a row to show that reference on the left, including references in other files. Up and Down walk the list, Left and Right fold a file, Enter or a double-click opens the location, and Escape closes the peek.
- **The peek starts on the reference you invoked it from.**

## A bounded hover card

- **Hovers are a card at most 700px wide and 420px tall,** scrolling when longer. The signature sits on top with a rule under it, text wraps, and code blocks scroll sideways inside the card. Short hovers shrink to fit.

## Sticky scroll

- **Pinned rows are solid and line up with the editor's lines,** so the code underneath no longer shows through.
