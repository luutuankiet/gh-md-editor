# v0.29.0: Change Language Mode, and new buffers detect their own language

In server mode, a code tab's language came only from its file name. A new untitled buffer stayed plain text until you saved it, and the language picker was a long unfiltered dropdown. This release adds VS Code's Change Language Mode and automatic language detection.

## Change Language Mode

- **Pick a language from a filterable list.** Click the language button at the top right of a code tab, or run `Change Language Mode` from the command palette (`Ctrl/Cmd+Shift+X`). Type to filter by name or alias (`pyth`, `ts`, `sh`), then press Enter.
- **The list starts with `Auto Detect`,** then `plain text`, then every language by name.
- **A picked language sticks to the tab.** It survives switching tabs and reloading the page.

## Auto Detect

A tab that is not pinned to a language works out its own language, in this order:

1. The file name, as before.
2. A shebang line such as `#!/usr/bin/env bash` or `#!/usr/bin/env python3`.
3. A small language model that reads the text, for buffers with no file name or a name that says nothing (`Untitled-1`, `notes`).
4. Plain text.

- **A detected language shows `(auto)` after its name,** for example `Shell (auto)` or `Go (auto)`. A picked language, or one from the file name, shows the bare name.
- **Picking `Auto Detect` drops the pin** and goes back to the detected language.
- **Detection waits until you pause typing,** reads only the first 10 KB of the active tab, and keeps the current language when it is not confident.
- **The model runs in the browser, off the main thread, and is loaded only the first time a buffer needs it.** It is served by your own host, so nothing leaves the machine and it works offline.

## Save As uses the language

Save As on an untitled buffer pre-fills the extension of its current language, so a detected shell script is offered as `Untitled-1.sh`. After saving, the new file name decides the language. A picked language is kept only when the new name maps to no language. Saving as `.md` still opens the file as a markdown tab.
