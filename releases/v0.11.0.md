# v0.11.0 — `--tunnel` installs its own tunnel, and the explorer follows the editor

- **`--tunnel` now downloads cloudflared itself** — it is a ~39MB per-platform Go binary, so it cannot be an npm dependency without taxing every install for the few who tunnel. First use fetches it once into `~/.cache/gh-md-editor` and every later run reuses it, which makes `--tunnel` a genuinely zero-setup flag: verified end to end on a host with nothing installed, cold start to live public HTTPS URL in about 45 seconds.
- **`--tunnel funnel` explains itself instead of failing** — Tailscale Funnel needs a root daemon that is logged into a tailnet, which no download can arrange, so a missing `tailscale` now returns that in one sentence and points at plain `--tunnel` as the no-setup path.
- **Missing host tools are announced at startup** — ripgrep and git each back a whole panel and neither can ship via npm. The banner now names what is absent, what breaks, and the exact `apt-get` / `brew` line. The README gained a table of optional host tools with the consequence of skipping each.
- **Quick open no longer fails silently without ripgrep** — it used to resolve to an empty file list with no error at all, so an absent `rg` looked like a workspace with no files. It now reports the cause, the way search always did.
- **Editor tabs show the containing folder** — dimmed beside the filename, relative to the anchored workspace, so two tabs called `index.ts` stay distinguishable.
- **The explorer reveals the active file** — switching tabs expands every ancestor folder, fetching subtrees that were never opened, highlights the row and scrolls it into view.
- **Both trees draw indent guides** — per-depth vertical lines in the explorer and the source-control tree. In the explorer the guide for each ancestor of the active file is lit, giving a visible trail from the workspace root down to what is open.
