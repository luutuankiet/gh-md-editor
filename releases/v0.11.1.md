# v0.11.1 — a code outline in the explorer, and it reads JSON too

- **The explorer gained an Outline section** — collapsed by default at the bottom of the file tree, remembering that choice per workspace. It lists what the active editor holds: declarations for code, headings for markdown, each with a VS Code-style symbol icon (callables purple, data blue, types orange) and per-depth indent guides. Grammar-driven where CodeMirror has one, with an indentation-based fallback so `.svelte`, shell and config dialects outline instead of showing an empty panel.
- **JSON files outline without a language server** — the JSON grammar already shipped with the editor and was wired only for highlighting. Keys now nest the way the document nests, objects and arrays carry container icons, and leaf keys show their value inline, which turns the panel into a schema scan for an unfamiliar file.
- **Large files no longer pay the full-document parse budget** — above 400KB the outline uses whatever the incremental parser has already covered instead of burning 150ms on every document change. A 4.4MB / 280k-line JSON opens with a usable outline in about 1.4 seconds and holds a 27ms keystroke-to-frame time; without the guard every keystroke in a large file stalled the frame.
- **Collapse-all in both trees** — one button beside the explorer's refresh, one in the Outline header. Both are toggles rather than one-way doors: pressing again restores exactly the folders or sections that were open before.
- **The explorer re-reads from disk on demand** — a refresh button for when a terminal command, another session, or an agent changes the workspace behind the browser's back. Expanded folders and the active file survive the reload.
- **Delete and shift-range selection in the explorer** — the context menu deletes the selection (folders recursively, behind a confirmation naming every item), and tabs backed by a deleted file close instead of lingering as ghosts. Shift+click extends across visible rows, alongside the existing Cmd/Ctrl+click.
- **Workspace-aware terminals, palette and markdown panes** — new terminals start in the anchored workspace folder; the command palette gained "open folder as workspace" in this tab or a new window plus a `#` prefix that searches folders; the markdown editor/preview split ratio is remembered per workspace rather than per file, so the next file opens at the ratio last set.
- **Fixes** — a restored session left the outline empty because a tab mounts only after its content arrives; the outline was truncated to the parsed viewport (18 of 41 symbols on a reopened file); and quick open could paint stale file results under the folder glyph after a switch to `#` mode, handing a file path to "open workspace here".
