# v0.9.1 — server mode: run the editor over any folder

- **`npx @luutuankiet/gh-md-editor` serves a folder in the browser** — new Node server (`server/index.mjs`) with a lazy file tree, preview/pinned tabs, and `Cmd/Ctrl+S` write-back guarded by an mtime-conflict prompt. Binds loopback by default; `--host` / `--port` / `--token` open it up deliberately.
- **`.md` keeps the three-pane cockpit, everything else gets a plain editor** — non-markdown files open in CodeMirror with filename-based language detection and a GitHub-Dark highlight palette matched to the shell.
- **Integrated terminal** — multiple server-owned pty sessions. Closing a browser tab no longer kills the shell, reattaching replays scrollback, and every child process is reaped on server exit.
- **Workspace search** — streamed ripgrep with literal/regex/word/case toggles and glob includes; click a hit to open that file on that line.
- **Git source control** — repo discovery, changed-files view, diff tabs, and line-level stage / unstage / revert.
- **Quick open and a ports panel** — fuzzy file jump, plus detection of ports the workspace is listening on.
- **Editor: double-click a word to highlight its other matches** — blue scrollbar ticks beside the amber `Cmd+F` ones, tick rail widened to 24 px. Unlike the always-on cursor-word highlight removed in v0.8.0, this only fires when the selection is exactly one whole word.
- **Published to npm with provenance** — pushing a `v*` tag publishes through GitHub OIDC trusted publishing, no token stored in CI. MIT LICENSE added.
