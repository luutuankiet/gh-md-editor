# v0.14.0 — npx runs with no toolchain, and the tunnel URL works the moment it is printed

- **The integrated terminal no longer needs a compiler** — the pty is a prebuilt binary chosen per platform, so there is nothing to build. It used to compile from source, which meant `make`, `g++` and `python3` on Linux; on a machine without them `npx` aborted with no output at all, because npm hides install-script failures.
- **macOS terminals stop failing with `posix_spawnp failed`** — the upstream package publishes its spawn helper without the executable bit. The prebuilt used here has correct modes, and the server repairs the bit at boot anyway.
- **ripgrep ships with the package** — workspace search and quick open silently returned nothing on any machine without a host `rg`, which looks like "no matches" rather than a missing dependency. A host copy is still preferred when present.
- **Both native pieces are optional** — a platform with no prebuilt prints one warning and keeps running. As hard dependencies, a failed native install killed `npx` outright.
- **The public tunnel URL is verified before it is printed** — cloudflared prints a hostname before its DNS record exists, and opening it early makes the resolver cache the failure, so the link keeps failing for minutes after it goes live. The URL is now resolved through public resolvers and fetched over the edge before being shown. Observed waits ranged from 1s to over 133s on the same machine.
- **A slow hostname is abandoned rather than waited out** — up to three draws, each a fresh name. Tailscale Funnel gets one attempt, its hostname being fixed.
- **A tunnel that dies is replaced** — a 60s check re-probes the live URL and announces a replacement, instead of leaving a dead link as the only thing in the scrollback.
- **`code-gh` is actually published** — the shim was tracked in the repo but missing from the package file list, so in an installed copy the command was never on PATH.
