# v0.32.0: language servers closer to VS Code

Language features now come from the language server the way VS Code does it. Reference counts and peek are exact, the hover card carries problems and fixes, settings are remembered per workspace, and Python, YAML, JSON and Dockerfile files get the tooling you would expect.

## References and peek

- **The "N references" lens and Find All References come only from the language server.** The text search fallback is gone, so counts are exact. Like VS Code, the lens leaves out the declaration and Find All References includes it.
- **The peek is a real editor.** Edit inside it and save, with VS Code keys. Alt+X opens references.

## Hover card, quick fixes, rename

- **One hover card shows the problem, the rule as a link, the type, and actions:** View Problem (Alt+F8), Quick Fix (Ctrl+.) and the preferred fix as a button. A light bulb marks lines with a problem.
- **F2 renames across the project,** including files open in background tabs and closed files on disk.
- **F8 and Shift+F8 move between problems.** Shift+Alt+F formats through the server when it offers formatting.
- **Error underlines survive a page reload.** The server replays the last diagnostics for each file.

## Settings and status

- **Language server choices are remembered per workspace,** outside the project folder, and a server you started comes back by itself next time. Nothing heavy starts unless you chose it.
- **The status bar shows each server's state** with a menu to start, stop and restart.

## Python

- **A Python interpreter picker in the status bar** lists the workspace venv, uv-managed Pythons and the system Python. Switching takes effect without restarting the server, and it warns when `pyrightconfig.json` sets `venvPath`.

## YAML, JSON and Docker

- **YAML, JSON and Dockerfile language servers,** started from the Language Servers panel.
- **SchemaStore schemas by file name,** plus a schema picker in the status bar with versions (for example dbt 1.5 or latest). Compose files are validated, and dbt `profiles.yml` gets a working schema.

## Fixes

- Stopping a language server waits for it to exit, and a server that already exited is not killed again.
- Unknown fields in a settings update are rejected.
