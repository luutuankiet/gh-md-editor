# v0.37.0: search and replace

The search panel can now replace, laid out like VS Code's.

## Replace

- **A chevron beside the search box opens a replace box.** It works with the existing match case, whole word and regular expression toggles, and adds an **AB** toggle that preserves case: replacing `foo` with `bar` turns `Foo` into `Bar` and `FOO` into `BAR`.
- **Regular expression mode expands `$1`, `$<name>`, `$&` and `$$`,** plus `\n` and `\t`, the way VS Code reads its replace box.
- **Results preview the change** with the old text struck through in red and the new text in green.
- **Replace one match, one file, or everything.** Hover a match or a file for its replace button; the button beside the replace box (or Ctrl+Enter) replaces every result shown, after asking first.
- **Only what you reviewed is changed.** Each match is re-checked against the file before writing; a line that changed since the search is skipped and counted in the message. Line endings and symlinks are kept, and files that are not valid UTF-8 are left alone. Open tabs re-check the disk afterwards: clean tabs reload, and tabs with unsaved edits show the "changed on disk" banner instead of being overwritten.

## Search

- **A "..." button shows or hides the search details,** now labelled "files to include" and "files to exclude", with the git-ignored checkbox. Excludes win over includes. Both toggles are remembered in this browser.
