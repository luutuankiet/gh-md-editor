# v0.19.1

Patch on top of v0.19.0.

A stray control character had made it into the Source Control panel's source
file. It was harmless at runtime — it sat inside a string used only to compare
one merge message against another — but it made git treat the whole file as
binary, so the v0.19.0 diff for that file showed as `Bin 20128 -> 22489 bytes`
instead of reviewable lines. Replaced with an ordinary separator.

No behaviour changes.
