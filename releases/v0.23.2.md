# v0.23.2 — terminals stay in the workspace you opened them from

A small release with one thing in it: the terminal panel no longer hands you a
shell belonging to a different workspace.

## The shell you get is the one for the folder you are in

With two workspaces open in two browser tabs, opening the terminal panel in the
second one did not always give you a shell for that folder. Shells live on the
server so they survive a reload, and the server keeps them all in one list —
but the panel adopted whichever shell came first in that list, regardless of
which folder it had been started in. Often that was the other tab's shell. It
also meant a workspace with no shell of its own would attach to a neighbour's
instead of opening one, because as far as the panel was concerned a terminal
already existed.

The result was a terminal that looked like yours and was not. Commands ran in
the wrong checkout, and with a single shell open there was no list on screen to
show which folder it actually belonged to.

The panel now only adopts shells belonging to the workspace the window is
anchored to, and opens one if there are none. A shell started in a subfolder
still counts as part of the workspace above it, so `Open terminal here` on a
subdirectory keeps the shell where you would expect. A window opened on the
served root behaves like any other workspace — it holds the shells started
there, not every shell on the machine.

Shells from other workspaces have not gone anywhere. They stay in the list,
grouped by folder and collapsed, so a stray shell in another checkout is still
reachable and still easy to kill. What changed is that none of them is ever
selected for you.

## The panel opens a shell when you open it, not when the page loads

Opening a terminal used to happen while the page was loading, whether or not
the panel was ever shown. Every workspace tab left open therefore held a login
shell nobody had asked for, and the more tabs you kept the more of them piled
up. The first shell is now started when the panel is first shown. If you keep
the panel open, nothing about this is visible to you; if you keep it closed,
you no longer pay for a terminal you never opened.
