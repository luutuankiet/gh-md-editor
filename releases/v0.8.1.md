# v0.8.1 — Preview pane: click-word highlighting removed

Companion to v0.8.0, which removed the same behavior from the **editor** pane.
The preview pane kept its own copy; this release removes it too, so neither pane
lights up word occurrences just because you clicked somewhere.

## What changed

Clicking a word in the rendered preview no longer highlights every other
occurrence of that word (faint blue inline shading) and no longer paints blue
ticks on the preview's right-hand scrollbar gutter.

**Explicit search is untouched.** `Cmd/Ctrl+F` in the preview still works exactly
as before: overlay top-right, yellow match highlighting, orange active match,
scrollbar ticks for real search hits, `Enter` / `Shift+Enter` to step, auto-expand
of collapsed `<details>` around the active match, `Esc` to close.

## Why

The implicit highlight fired on every left-click anywhere in the reading pane.
When the pane is being used as a reading surface — which is the whole point of
this app — an incidental click to place focus repainted a chunk of the document
and the scrollbar. It read as noise, not as a feature.

## Files touched

| File | Change |
|---|---|
| `src/components/PreviewSearch.svelte` | Removed the click listener, `implicitQuery` / `implicitMatches` / `implicitTickPositions` state, the `gmd-search-implicit` highlight registration, the implicit tick markup, and the associated CSS (light + dark). |
| `src/components/ShortcutsDialog.svelte` | Dropped the "Left-click on a word" preview row; corrected the editor `Cmd+F` description, which still described the cursor-word shading removed in v0.8.0. |
| `src/components/App.svelte`, `src/components/App-vscode.svelte` | Sample-doc feature tour: removed the click-a-word step, renumbered the rest, updated the pane-comparison table. |

## Not affected

- Editor pane `Cmd+F`, match ticks, multi-cursor (`Cmd+D`, `Alt+Click`)
- Right-click reveal in either direction
- Outline, themes, mermaid pan/zoom, GitHub asset resolution

The change lives in shared components, so the VS Code extension picks it up on
its next build.
