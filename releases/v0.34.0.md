# v0.34.0: your own YAML and JSON schemas, a readable resizable peek

YAML and JSON files can now be checked against any schema you point at, not only the SchemaStore list, and the inline peek finally shows where you are typing.

## Custom schemas

- **"Enter schema URL or path..." in the schema picker** (the `{}` item in the status bar). It takes an `http(s)` URL, an absolute path, a `~/` path, or a path relative to the workspace.
- **Checked before it is saved:** a missing file, a `.json` file that does not parse, an unreachable URL or an unsupported scheme is reported in the picker. A schema's `title` names it in the status bar.
- **Recent custom schemas** (the last eight) are listed at the top of the picker, kept in this browser. Typing something that looks like a URL or a path into the search offers to use it directly.
- **Saved per file,** like any other schema pick, and applied at once without restarting the language server.

## Peek

- **The caret and selection show** inside the peek's editor. Typing and saving already worked; you just could not see where.
- **The code uses the editor theme's own background** instead of a dark blue tint, and the scrollbars follow the dark or light theme.
- **Drag the bottom edge to resize the peek.** The height is remembered in this browser and used by every peek after.
