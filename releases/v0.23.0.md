# v0.23.0 — folding the peek panel, and two things that would not stay put

A maintenance release on top of the reference work in v0.22.0: the peek panel
learns to answer "which files" before "which lines", a revealed secret stops
staying revealed, and the git sidebar stops hiding the one character each row
exists to report.

## The peek panel folds by file

A peek over a busy symbol opens with a dozen files in it, and the first
question is usually which files use it — not which lines. Every file group is
now a header you can click shut, leaving the name and its hit count. A
`collapse all` control in the panel header does the whole list at once, so a
long result reads as a short list of filenames and then expands where it
matters.

The keyboard follows the same shape as every other tree here: `←` folds the
group holding the selection, `→` unfolds it. `↑` and `↓` walk only what is on
screen — stepping into a folded group would move the preview to a location the
list is no longer showing.

## A revealed .env value covers itself again

The cloak over `KEY=value` lines could be lifted a line at a time by clicking a
pill, which was the intent — but the reveal was permanent. Click four values
over the course of reading a file and four secrets stayed on screen, in a file
that still looked protected.

A reveal is now anchored to the cursor. Clicking a pill uncovers the value and
puts the cursor on that line; moving off the line covers it again. The window
in which a secret is readable is now exactly as long as you are looking at it,
which is the guarantee the feature was supposed to make in the first place.

## The git status letter stops falling off the edge

Rows in the source control panel were built to grow: a long filename widened
the row, and the `M`, `D` or `U` at the end went past the right edge of the
panel where only a sideways scroll would find it. The rows in a sidebar exist
to report that letter, so the letter now holds a fixed column and the filename
gives way with an ellipsis instead — the trade every other git sidebar makes.
The full path is still on the row's hover title, and on very deep trees the
indent guides stay aligned.
