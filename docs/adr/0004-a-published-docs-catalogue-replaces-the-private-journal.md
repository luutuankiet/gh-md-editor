# A published documentation catalogue replaces the private journal

This repository's durable knowledge lived in an untracked `gsd-lite/` journal —
around 44 MB across 97 files, of which roughly 900 KB was prose and the rest was
build logs, fixtures, `.bak` copies, probe scripts and a vendored binary. It has
been promoted into `AGENTS.md` plus five architecture pages, nine trap pages, three
reference pages and these decision records, and the journal is retired.

## Considered options

**Keeping the journal alongside the catalogue** was rejected. A second store of
truth is how the first one rotted: the journal's own architecture file listed six
source paths, five of which had never existed, and every code line number in it had
drifted — one by 79 lines. Once the pages are committed, `git log` is the archive.

**Committing the journal as-is** was rejected on provenance rather than privacy.
Most of it was material that merely passed through the project — captured logs,
render fixtures, another project's review text — not knowledge this project produced.
Promotion is therefore a rewrite into published voice, never a copy; that rewrite is
what makes it safe to publish.

## Consequences

What was loaded at the start of every session drops from roughly **58 KB** of
journal prose to an **11-byte** `CLAUDE.md` plus a **5.4 KB** `AGENTS.md`. Everything
else is reached on demand through `docs/README.md`, which is generated by
`scripts/gen-docs-index.sh` and must never be hand-edited.

Two things were relaxed to make this work. `.gitignore` still excludes `.claude/`
but now admits `.claude/skills/`, because the two index skills are the mechanism by
which a future session finds the catalogue at all. `npm run gates` was widened to
match, so it blocks private paths without blocking those skills.

Roughly 43 MB of the journal — the temporary directory, the reference corpus and a
credential file — was discarded rather than promoted. The credential was never
opened and wants rotating on general principle.
