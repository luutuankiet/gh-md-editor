# v0.35.0: search inside git-ignored files

Search can now look inside files that `.gitignore` hides, such as a local `tmp/` folder.

## Search

- **"Include git-ignored files" checkbox** under "files to include". When it is ticked, `.gitignore` rules are lifted everywhere, including in git repositories nested inside ignored folders, so their own ignored files are found too. The choice is remembered in this browser.
- **Bounded so a wide-open scan cannot hog the host:** `node_modules` stays excluded unless "files to include" names it, `.git` folders and other hidden paths are still skipped, `.ignore` and `.rgignore` files are still honoured, the scan uses at most 4 threads, and it stops after 30 seconds and reports the results so far as truncated. The usual limits of 2000 matches and 2 MB per file still apply.
