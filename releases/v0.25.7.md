# v0.25.7 — a symlinked folder is a folder

- **Linked folders open, expand and edit like the real thing.** The explorer classified each entry from what `readdir` reports, and that is `lstat` data: a symlinked directory arrives as neither a file nor a directory, so it landed in a third shape the tree has no branch for. It drew with no chevron, refused to expand, and clicking it asked the file endpoint for a directory and got `not a file` back — visible and completely inert. Links now resolve to what they point at, exactly as the workspace picker has always done, so a linked folder behaves as a folder everywhere: chevron, expand, paste target, terminal here, download as zip. A broken link degrades to a file, so the read error surfaces in a tab instead of a folder that opens onto nothing.

- **Quick open and search see through a link.** The ripgrep calls behind quick open, the search panel and the symbol lookups ran without `--follow`, so every file inside a linked folder stayed invisible to them even once the tree could reach it. They follow links now. A file reachable by two paths is listed under both, which is what following means.

- **Saving into a linked file no longer replaces the link.** Writes publish through a temporary file and `rename`, and renaming onto a symlink replaces the link itself: the edit landed on a new regular file where the pointer used to be while the real file kept its old contents — silently, with a successful save reported. The final hop is resolved before the swap, so the bytes reach the file the tab actually opened and the link survives.

- **Downloading a linked folder produces its contents, not a 404.** The archive walk refuses to follow symlinks — they invite walk loops and can point clean out of the workspace — and that refusal also swallowed the link the download was *asked for*, so the walk found nothing and the request failed. The selection itself is now resolved before the walk starts, while links met along the way are still left alone, so the guard keeps doing the job it was written for. The archive is named after the entry that was picked rather than whatever it points at.

No storage format change. Directory listings now carry `link: true` on entries that are symlinks; nothing reads it yet.
