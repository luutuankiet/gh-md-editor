# v0.15.1 — A branch-compare sidebar, per-change arrows, and downloads from the explorer

- **A third sidebar view compares the working tree against any ref** — pick a branch, tag or remote and get the changed files as a tree. Merge-base by default so only this branch's own work shows, `direct` for a head-on tree comparison.
- **The base a comparison resolved to is pinned for the whole session** — the server returns the commit sha it settled on, so a later per-file diff or restore reads the same tree even if `HEAD` moves underneath.
- **Restore a hunk, or selected lines of it, from the base** — the only write a pinned tree can coherently accept. Stage and unstage are refused there, because both are index-relative and the index is not what is being viewed.
- **Copy a change onto either side of any comparison** — VS Code's per-change arrows, for compares of two arbitrary files. The diff is recomputed server-side at apply time, so a stale browser view is rejected rather than silently corrupting a file.
- **Right-click in the explorer to download files and folders** — a single file streams as itself, a folder or multi-selection arrives as a zip. Written without a zip dependency, so it works wherever the server runs.
- **Downloads show progress and can be cancelled** — a small card, not a modal, with live bytes against the size the server measured while walking. Cancelling closes the connection, which stops the walk rather than leaving it packing an archive nobody will receive.
- **Comparing with the clipboard no longer opens a paste modal** — the clipboard API needs a secure context this server rarely has, so a slim bar arms a catcher and the paste itself opens the diff. Touch paste menus are covered too.
